# Portfolio Website

This is a simple static portfolio site made with HTML, CSS, and JavaScript.

## Edit Your Details

Open `index.html` and replace:

- `Your Name`
- `your.email@example.com`
- `your-username`
- The project names and descriptions
- The about section text

## Upload to GitHub Using the Website

1. Go to [GitHub](https://github.com) and sign in.
2. Click the `+` button in the top-right corner and choose `New repository`.
3. Name it something like `portfolio` or `your-username.github.io`.
4. Keep it public if you want GitHub Pages to be easy to share.
5. Click `Create repository`.
6. Click `uploading an existing file`.
7. Drag in all `.html` files, plus `styles.css`, `script.js`, and `README.md`.
8. Click `Commit changes`.

## Turn On GitHub Pages

1. Open your repository on GitHub.
2. Click `Settings`.
3. Click `Pages` in the left menu.
4. Under `Build and deployment`, choose `Deploy from a branch`.
5. Choose the `main` branch and `/root`.
6. Click `Save`.

GitHub will publish your site after a minute or two. The page will show your live website link.
